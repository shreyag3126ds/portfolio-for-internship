# Internship Project Portfolio

This is a static portfolio dashboard linking to six independently hosted projects.

## Publish with GitHub Pages

1. Create a new **public** GitHub repository named `internship-project-portfolio` (or another name you prefer).
2. Upload `index.html` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait for the deployment to finish. GitHub will show the published site URL in the Pages section.

The final URL will usually look like:
`https://YOUR-GITHUB-USERNAME.github.io/internship-project-portfolio/`

GitHub Pages hosts the portfolio page only. The six project links still point to their existing Render deployments.
